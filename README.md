# Portfolio 2026

Shreyas Visweshwaran — MS CS @ NC State · Incoming SWE Intern, Goldman Sachs AWM (Summer '26).
A cinematic portfolio. TypeScript end-to-end.

## Quickstart

```bash
npm install
npm run dev
```

- Client: http://localhost:5173
- Server: http://localhost:4000

## Stack

- **Frontend** — React 18, TypeScript, Vite, Tailwind, GSAP, Three.js, R3F, Framer Motion, Lenis
- **Backend** — Node.js, Express, TypeScript

## Scripts

| Script | What it does |
| --- | --- |
| `npm run dev` | Run client + server together |
| `npm run build` | Build both packages |
| `npm run start` | Start the production server |
